# Suporte

## Onde tirar dúvidas

O GitHub é onde ficam nossos templates e projetos de exemplo, mas não é o canal mais rápido para dúvidas de aula.

- **Comunidade NoCode StartUp:** [open.nocodestartup.io/feed](https://open.nocodestartup.io/feed). Alunos e instrutores respondendo todos os dias.
- **Plantões de dúvida ao vivo:** 3x por semana, dentro da plataforma, para alunos.
- **Contato comercial:** [nocodestartup.io/contato](https://nocodestartup.io/contato).

## Quando abrir uma issue aqui no GitHub

Abra issue quando o problema estiver no material publicado: um template que não roda, um fluxo com erro, uma instrução errada ou desatualizada no README.

Dúvidas sobre acesso à plataforma, pagamento ou conteúdo das aulas não passam por aqui. Para essas, use a comunidade ou o contato do site.
